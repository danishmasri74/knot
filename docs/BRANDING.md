# Knot app icon

The current icon is an ivory woven ribbon knot on a forest-green rounded tile. The same artwork appears in the desktop icon, installer assets, sidebar and favicon.

- Source artwork: `public/knot-icon.png` (1254 × 1254 RGBA; generated with the built-in image generation tool, 28 October 2026).
- Platform assets: `src-tauri/icons/`, generated with `pnpm tauri icon public/knot-icon.png`.
- Tauri bundle icons are explicitly configured in `src-tauri/tauri.conf.json`.
- `public/knot.svg` is the older overlapping-square artwork and is no longer referenced by the app.

Generation prompt:

> Use case: logo-brand. Create a finished square desktop application icon for Knot, a calm local notes and whiteboard app connecting ideas. One bold ivory woven knot symbol centered on a deep forest-green rounded-square tile (#426d57). The symbol is a beautifully balanced continuous ribbon with four rounded loops and clear over-under crossings, distinctive and simple, not a command-key glyph, not chain links. Flat vector-like precision, generous strokes and negative space, legible at 32 pixels. Subtle tonal green depth allowed, no glossy 3D, no tiny detail, no lettering, no wordmark, no shadow outside the tile, no mockup. Tile fills the square canvas with rounded corners, actual transparent pixels outside corners. Center symbol occupies about 65 percent of tile width. Deliver one icon only, 1024x1024.
