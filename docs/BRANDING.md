# Knot app icon

Knot uses the Linked K identity: a warm-white mark on a charcoal rounded square for the desktop icon, installer and favicon, and a standalone charcoal mark in the sidebar.

See [identity guidelines](IDENTITY.md) for canonical artwork, colors and platform-icon regeneration instructions.

- App-icon source: `assets/knot.svg`; public favicon copy: `public/knot.svg`.
- Raster fallback: `public/knot-icon.png`.
- Platform assets: `src-tauri/icons/`, configured in `src-tauri/tauri.conf.json`.
- Attachment-test image: `tests/fixtures/knot.png`, copied from `src-tauri/icons/128x128.png`.
