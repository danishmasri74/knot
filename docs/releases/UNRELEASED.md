# Unreleased

<!-- One line per change a user would notice. Moved into docs/releases/<version>.md on release. Note: the version is already set to 0.3.1 for this batch. -->

- Your settings, recently visited notebooks and pinned collections are now kept safe if Windows resets Knot's browser storage.
- Restoring a backup keeps your recently visited notebooks, pinned collections and favorites order.
- A notebook you import now shows under Recently visited.
- Empty Trash now also permanently deletes the cards waiting in Trash.
- You can move notebooks and cards to Trash from the Library, and rename notebooks there.
- Open in notebook on a Library card now opens the notebook at that card instead of returning to the Card Deck.
- On the canvas, Add note puts the new note where you're looking and keeps you on the canvas, ready to type.
- A new notebook's canvas opens centered on its notes, and the selected note stays visible when a side panel opens.
- Page view names the note you're in (Notebook / note) in the top bar, and an empty note shows where to type, with the cursor already in it.
- Side panel tabs share the space evenly and shrink before they overflow; extra tabs scroll with the mouse wheel, with faded edges instead of a scrollbar.
- An empty note has the same name everywhere (for example "Note 3"), including its side panel tab.
- The sidebar opens your notebook in one place only, remembers whether it's collapsed and which sections are open, and pinned collections start open.
- Add to Favorites is now in a notebook's ⋯ menu in the sidebar, and empty sidebar sections show a short hint instead of large placeholders.
