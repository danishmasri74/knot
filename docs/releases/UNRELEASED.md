# Unreleased
- Arrow labels in the default black, including those Ask Knot made before 0.6.3, are now readable on a dark canvas instead of leaving gaps in the lines.
- Tidy tangled arrows with reroute points: Alt+click an arrow (or right-click it) to add a dot you can drag, bundle several arrows into one dot, double-click a dot to jump to what it points at, and delete it to join the arrows back. Ask Knot reads arrows through these dots.
- Typing an arrow label works again: the text goes into the label instead of sitting over an "Add text" placeholder, it is readable on a dark canvas, and it uses the same font as the canvas instead of a serif one.
