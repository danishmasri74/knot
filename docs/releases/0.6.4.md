- Tidy tangled arrows with reroute points: Alt+click an arrow (or right-click it) to add a dot you can drag, bundle several arrows into one dot, double-click a dot to jump to what it points at, and delete it to join the arrows back. Ask Knot reads arrows through these dots.
- Typing an arrow label works again: the text goes into the label instead of sitting over an "Add text" placeholder, and it uses the canvas font instead of a serif one.
- Arrow labels in the default black, including those Ask Knot made before 0.6.3, are now readable on a dark canvas.
- Note in a column's + menu lists the notebook's notes, with a search box for long lists, so you choose which note opens.
- New setting (Settings → Editor → Card Deck): permanently delete blank cards that aren't on any canvas, every 1 day to 1 month. It is off unless you turn it on.
- Settings are easier to scan: each page groups its options into titled sections.
