# Knotbook file icon

Approved option 1: a charcoal bound notebook with the ivory Knot mark.

- `knotbook.ico`: Windows icon with 16, 20, 24, 32, 40, 48, 64, 96, 128, and 256 px RGBA PNG frames.
- `knotbook-master.png`: original transparent master.
- `16x16.png` through `512x512.png`: transparent PNG exports made with the Tauri icon CLI.

These assets are prepared for future `.knotbook` file associations. They do not register a file association or replace Knot's application icon.

## Creation

Generated with the built-in image generation tool, using the approved Signature notebook concept as the edit target. PNG sizes were exported with `pnpm tauri icon`; the ICO packages those PNGs without further image changes.

### Final generation prompt

Use case: background-extraction / precise-object-edit. Edit the provided approved Knotbook icon concept into the final production icon master. Preserve this exact charcoal closed notebook design, its bound left spine, rounded right corners, ivory bottom and right page edges, and the exact large ivory geometric Knot K mark with the same proportions and position. Remove the entire pale background and any ground shadow to true alpha transparency, not a checkerboard painted into the image. Slightly simplify fine cover texture and tiny page lines for desktop icon clarity, while keeping the approved appearance and subtle cover/spine shading. Center the book on a square transparent canvas with a consistent small safe margin, book occupying about 90 percent of canvas height, no cropping. Crisp smooth silhouette and clean antialiased edges without pale fringe. No new features, no captions, no enclosing tile, no extra badge, no ribbon. Output only the single isolated finished icon.
